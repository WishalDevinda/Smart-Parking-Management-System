# AutoSlot Frontend

React (Vite) using JSX. Uses the provided color palette. Do not change header and background colors.

Create `.env` to point to the backend API:

```
VITE_API_BASE=http://localhost:4000/api
```

Run (PowerShell):

```
npm install
npm run dev
```

Pages: Login, Dashboard, Analysis, Live Slot. SSE used for realtime slot updates.
